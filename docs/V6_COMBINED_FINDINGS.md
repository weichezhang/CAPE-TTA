## 下一研究门槛

Oracle 可行性线索已存在，但完整 CAPE-TTA 尚缺：
1. 不依赖 simulator state / counterfactual future 的可部署进展证据；
2. 明确的参数更新损失、可训练参数、接受/拒绝及回滚机制；
3. 分离的开发/拟合、校准和最终测试数据；
4. 等算力随机候选、未校准选择、未经门控适应等公平对照；
5. 独立任务/状态完整回合评测、负例与不确定性分析。

如果研究只保留候选动作筛选，应相应调整论文题目与定位，不能称为已实现
测试时参数适应。继续重复同一开发任务的 Oracle 比较不能补齐上述缺口。
